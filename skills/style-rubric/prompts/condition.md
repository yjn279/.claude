# Condition Extraction

## Input

検証データに含まれる文章のうち、 `1` 件の本文全文。

```
<source_text>
（検証データの1件の本文）
</source_text>
```

## Output

条件入力として、主張・事実・トピックだけを箇条書きで出力する。

> 元の文章：正直、あの映画は期待外れだった。脚本が雑すぎる。
>
> 出力：
> - ある映画の感想
> - 期待に届かなかった
> - 理由は脚本の粗さ

## Constraints

- 語彙・語順・言い回し・句読点の癖・トーンを残さない。原文の言い回しをそのまま使わない。
- 主張・事実・トピック以外（感想の強さの演出、比喩、修飾）は含めない。
- 元の文章の断片を引用しない。平易で無個性な一般語に言い換える。
- 出力はこの文章について一度だけ作成し、以降の全エポックを通じて固定して使い回す。エポックごとに取り直さない。
- メモリ機能を使わない。渡された入力だけを文脈とする。
