# Discriminator

## Input

```
<reference_samples>（学習データの見本、複数件。本人と分かっている文章）</reference_samples>
<target>（判定対象の1件。本人か生成文か不明）</target>
```

## Output

次の `2` つを含む JSON 形式で出力する。

```json
{
  "verdict": "本人 または 生成文",
  "reasoning": "判定の根拠を述べた文章"
}
```

## Constraints

- `verdict` は「本人」「生成文」のいずれか一方のみとする。
- `reasoning` を必ず出力する。根拠のない判定は情報量がゼロである。
- 見本と判定対象を見比べ、語彙・語形、文の長さやリズム、表記・記号・改行の使い方、論理展開、態度・トーン、話題の選び方など具体的な一致・不一致を根拠に含める。原文が酷似していてもそのまま転記せず、特徴を言葉で説明する。
- 判定対象は `1` 件だけを独立に判定し、比較対象は与えない。
- メモリ機能を使わない。渡された入力だけを文脈とする。
