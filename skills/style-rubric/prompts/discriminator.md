# Discriminator

見本を参照したうえで、提示された1件の文章が本人の筆か生成文かを判定し、その根拠を述べる言語モデル呼び出しである。判別の基準は「人間が書いたか AI が書いたか」ではなく「**本人が書いたか否か**」である。Discriminator は本人の文体を事前に知らないため、判定のたびに見本を与えて条件付けする。

比較対象は与えない。1件だけを独立に提示して判定させる。複数の候補を並べて相対比較させることはしない。

この呼び出しはメモリ機能を使わない。過去のエポック（1ラウンド。1回分の生成・判定・ルーブリック更新からなる）で見た文章についての記憶を参照せず、以下に渡された入力だけを文脈とする。過去に見た文章を覚えていると、文体の判定ではなく既知の文章の照合になり、**見破られ率**（この Discriminator の正答率。0.5に近いほど本人の文章と生成文の区別がついていないことを表す）が不当に高く出てしまう。

## Input

- 見本：学習データに含まれる、本人が書いたことが分かっている複数件の文章
- 判定対象：本人の文章か生成文か不明な1件の文章

```
<reference_samples>
（ここに学習データの見本を複数件貼り付ける）
</reference_samples>

<target>
（ここに判定対象の1件を貼り付ける）
</target>
```

## Output

次の2つを含む JSON 形式で出力する。

```json
{
  "verdict": "本人 または 生成文",
  "reasoning": "判定の根拠を述べた文章"
}
```

## Constraints

- `verdict` は「本人」「生成文」のいずれか一方のみとする。
- `reasoning`（判定根拠）を必ず出力する。根拠のない判定は、この仕組みにおいて情報量がゼロである。根拠はのちのルーブリック更新の材料になる、数値ではなく言葉で表現された更新の手がかりである。
- 見本と判定対象を見比べ、語彙・語形、文の長さやリズム、表記・記号・改行の使い方、論理展開、態度・トーン、話題の選び方など、具体的にどこが一致または不一致だったかを根拠に含める。
- 判定対象が見本の一部と酷似していても、その原文をそのまま根拠として転記しない。特徴を言葉で説明する。
