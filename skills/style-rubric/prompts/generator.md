# Generator

## Input

- ルーブリック：語彙と語形、統語とリズム、表記と記号と改行、論理展開の型、態度とスタンス、話題選好、長さの分布、禁則の `8` 項目
- 条件入力：書くべき内容の骨子を箇条書きにしたもの

```
<rubric>
（ルーブリックの全文）
</rubric>

<condition>
（条件入力）
</condition>
```

## Output

条件入力に挙げた主張・事実・トピックを過不足なく反映し、ルーブリックの規則にできる限り従った文章を `1` 件、本文のみで出力する。前置きや解説は付けない。

## Constraints

- 条件入力にない内容を付け加えない。条件入力にある内容を落とさない。
- ルーブリックが定める語彙と語形、統語とリズム、表記と記号と改行、論理展開の型、態度とスタンス、話題選好、長さの分布に従う。禁則に該当する表現は使わない。
- ルーブリック中の例示はごく短い断片である。そのまま連結して使わず、規則として汲み取ったうえで自分の言葉で書く。
- メモリ機能を使わない。渡された入力だけを文脈とする。
