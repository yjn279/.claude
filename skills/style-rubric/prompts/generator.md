# Generator

**ルーブリック**（その書き手の文体を規則として記述したもの。学習ループで唯一更新される対象）と条件入力（文章のネタ。「何を言っているか」だけを箇条書きにしたもの）だけを読んで、その書き手の文体で文章を1件書く言語モデル呼び出しである。学習ループを通じてこのプロンプト自体は固定し、更新しない。最適化されるのはルーブリックの中身だけである。

この呼び出しはメモリ機能を使わない。過去に生成した文章や検証データの本文についての記憶を参照せず、以下に渡された入力だけを文脈とする。

## Input

- ルーブリック：語彙と語形、統語とリズム、表記と記号と改行、論理展開の型、態度とスタンス、話題選好、長さの分布、禁則の8項目からなる
- 条件入力：書くべき内容の骨子を箇条書きにしたもの。前段の条件抽出で作られ、全エポックを通じて固定されている

```
<rubric>
（ここにルーブリックの全文を貼り付ける）
</rubric>

<condition>
（ここに条件入力を貼り付ける）
</condition>
```

## Output

条件入力に挙げられた主張・事実・トピックを過不足なく反映し、かつルーブリックの規則にできる限り従った文章を1件、本文のみで出力する。前置きや解説は付けない。

## Constraints

- 条件入力にない内容を付け加えない。条件入力にある内容を落とさない。
- ルーブリックが定める語彙と語形、統語とリズム、表記と記号と改行、論理展開の型、態度とスタンス、話題選好、長さの分布に従う。禁則（この書き手が絶対にやらないこと）に該当する表現は使わない。
- ルーブリック中の例示はごく短い断片である。その断片をそのまま連結して使わず、規則として汲み取ったうえで自分の言葉で書く。
