# Rubric Generation

## Input

- 学習データ：文体の観測元
- 前回のルーブリック：更新の起点。初回は空
- 判定根拠：直近バッチの判定根拠一覧。初回は空

```
<training_data>（学習データ全件）</training_data>
<previous_rubric>（前回のルーブリック。初回は空）</previous_rubric>
<verdict_reasons>（直近バッチの判定根拠。初回は空）</verdict_reasons>
```

## Output

語彙と語形、統語とリズム、表記と記号と改行、論理展開の型、態度とスタンス、話題選好、長さの分布、禁則の `8` 項目からなるルーブリックを Markdown で出力する。各項目に観測頻度・ごく短い例示・逸脱の許容範囲を記し、末尾に採用した特徴と捨てた特徴の件数を記す。

## Constraints

- `<previous_rubric>` と `<verdict_reasons>` が空なら、学習データだけを観測して `8` 項目を一から書く。
- 空でなければ、`<verdict_reasons>` の全根拠を特徴ごとに正規化して数え、バッチサイズの `15%` 以上（既定 `3` 件）のサンプルに共通して現れた特徴だけを更新対象にする。それ未満の言及は捨てる。
- 出現頻度の高い順に前回のルーブリックの該当項目を修正する。判定根拠に一度も現れなかった項目は統合または削除の候補とする。
- 例示は数語程度の断片に留め、原文を長く転記しない。
- 検証データの本文をルーブリックに書き込まない。
- 採用した特徴と捨てた特徴の件数を出力の末尾に必ず残す。
- メモリ機能を使わない。渡された入力だけを文脈とする。
