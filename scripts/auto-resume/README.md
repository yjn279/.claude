# auto-resume

使用量の上限に当たって会話が止まったとき、上限が解除される時刻に、その会話を自動で再開する仕組みである。対象は、フックが有効な会話が、解除の時刻を日付なしで示す上限（例「resets 9:10pm」）で止まった場合である。

解除の時刻に日付が付く上限（例「resets Aug 13 at 9pm」と示す週の上限）は対象にしない。数日先まで待つあいだに端末を再起動すると、待っている処理が失われるためである。フックを無効にして起動した会話（設定 `disableAllHooks` を渡したもの）も、上限で止まった合図を受け取らないため対象にならない。

## How It Works

会話が使用量の上限で止まると、Claude Code が `StopFailure` フック（ matcher `rate_limit` ）で `detect.mjs` を呼ぶ。呼ばれた側は受け取った情報を切り離した子の処理へ渡してすぐ戻り、会話の終了を待たせない。

子の処理は、フックが渡す `last_assistant_message` （画面に出た文字列そのもの）だけを見て判定し、次のいずれかに当たれば待たずに終わる。

- 上限の文面（ `hit your ... limit` ）ではない。
- 文面から日付なしの解除の時刻（例「resets 9:10pm (Asia/Tokyo)」）が読み取れない。日付の付いた時刻もここに当たり、仮の時刻は置かない。
- 同じ会話を待っている処理がすでに生きている。
- その会話の再開回数が上限に達している。

文面の地域名が書かれていなければ、この端末の地域の時刻として読む。書かれた地域名を知らない場合は時刻を計算できないため、失敗として記録して終わる。

待つと決めた子の処理は、そのまま解除の時刻まで生き続ける。実時刻を繰り返し見比べて待つため、途中で端末が眠っても、目覚めた時点から数え直しにならない。時刻になると、元の作業場所で止まった会話を画面なしで続きから動かし、そのあいだは端末を眠らせない。予定より大きく遅れた場合と、会話の記録が失われていた場合は再開しない。

待つのを macOS の予約ではなく切り離した子に任せるのは、macOS が自動で起こした処理には書類フォルダなどを読む許可がないためである。そこに置かれた会話を再開しようとすると、現在地を求める処理が止まったまま返らない。Claude Code から切り離した子は、必要な許可をそのまま引き継ぐ。

## Files

仕組みは次の 3 つのファイルからなり、呼び出しの設定は `~/.claude/settings.json` の `hooks.StopFailure` にある。

| ファイル | 役割 |
| :-- | :-- |
| `config.json` | 各しきい値。変更するのはここだけでよい |
| `detect.mjs` | 上限で止まったかを判定し、解除の時刻まで待ち、会話を再開する |
| `check.sh` | 上限を待たずに、仕組み全体をその場で確かめる |

## Configuration

しきい値は `config.json` にまとめてある。

| 項目 | 既定 | 意味 |
| :-- | :-- | :-- |
| `maxResumesPerSession` | `3` | 同じ会話を再開する上限の回数。再開してすぐまた上限に当たる場合の空回りを防ぐ |
| `resetBufferMinutes` | `3` | 解除の時刻に足す余裕 |
| `lateLimitMinutes` | `720` | この分数を超えて遅れたら再開しない。長く触っていない端末が古い作業を突然動かすのを防ぐ |
| `resumePrompt` | — | 再開したときに最初に渡す指示 |

仕組み全体を止めるには、 `~/.claude/settings.json` から `StopFailure` のフックを外す。一時的に止めるときは、環境変数 `CLAUDE_AUTO_RESUME` に `off` （ `0` ・ `false` も可）を入れて Claude Code を起動する。どちらの場合も、すでに待っている処理は止まらないため、 `~/.claude/auto-resume/state.json` で番号を調べて `kill <pid>` で終わらせる。

## Verification

上限に当たるのを待たずに、端から端まで確かめられる。

```shell
~/.claude/scripts/auto-resume/check.sh
```

使い捨ての会話を書類フォルダの下に作り、その会話が終わる瞬間に上限の文面を流し込み、数分後に本当に再開されるかを見る。最後に、作ったものをすべて消す。許可の要る書類フォルダの下を通ることまで含めて確かめる。

## Logs

記録はすべて git の管理外に残る。実際に上限に当たった後は、ここで結果を確かめられる。

| 場所 | 内容 |
| :-- | :-- |
| `~/.claude/resume-logs/detect.log` | 判定と再開の結果を一行ずつ。待たなかった理由もここに残る |
| `~/.claude/resume-logs/<再開時刻>_<セッションID>.log` | 再開した会話の出力 |
| `~/.claude/auto-resume/state.json` | 会話ごとの再開回数、待っている処理の番号、最後の結果 |
