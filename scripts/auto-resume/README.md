# 上限で止まった会話を自動で再開する

使用量の上限に当たって会話が止まったとき、上限が解除される時刻に、その会話を自動で再開する仕組みである。すべての会話が対象である。

## 動き

1. 会話が使用量の上限で止まると、Claude Code が `StopFailure` の合図（`rate_limit` のときだけ）でこの仕組みを呼ぶ。
2. 呼ばれた側は受け取った情報をすぐ切り離した子の処理へ渡して戻る。会話の終了を待たせない。
3. 子の処理が、合図が渡す `last_assistant_message`（画面に出た文字列そのもの）を見て判定する。
   - 上限の文面（`hit your ... limit`）でなければ何もしない。
   - 文面から解除時刻（例「resets 9:10pm (Asia/Tokyo)」）が読み取れなければ、仮の時刻は置かず何もしない。
   - その会話の再開回数が上限に達していれば何もしない。
   - 同じ会話を既に待っている処理が生きていれば何もしない。
4. どの場合も何もしなかった理由、または待ち始めたことが記録に一行残る。
5. 待つ場合は、子の処理がそのまま解除時刻まで生き続ける。実時刻を繰り返し見比べて待つため、途中で端末が眠っても目覚めた時点から数え直しにならない。
6. 時刻になると、元の作業場所で、止まった会話をそのまま続きから動かす。画面は開かず、裏で走る。再開のあいだは端末を眠らせない。
   予定より大きく遅れた場合と、会話の記録が失われていた場合は、理由を記録して再開しない。
7. 再開が終わると、終了コードを記録に残して子の処理は消える。

macOS へ予約を登録する形は採らない。自動起動された処理には書類フォルダなどを読む許可がなく、そこに置かれた会話を再開しようとすると現在地を求める処理が止まったまま返らないためである。Claude Code から切り離した子は必要な許可をそのまま引き継ぐ。

## ファイル

| ファイル | 役割 |
| --- | --- |
| `config.json` | 有効・無効と各しきい値。変更するのはここだけでよい |
| `detect.mjs` | 上限で止まったかを判定し、解除時刻まで待ち、会話を再開する |
| `check.sh` | 上限を待たずに、仕組み全体をその場で確かめる |

呼び出しの設定は `~/.claude/settings.json` の `hooks` の `StopFailure`（matcher `rate_limit`）にある。

## 確かめ方

上限に当たるのを待たずに、端から端まで確かめられる。

```shell
~/.claude/scripts/auto-resume/check.sh
```

使い捨ての会話を書類フォルダの下に作り、上限の文面を流し込み、数分後に本当に再開されるかを見て、最後に作ったものをすべて消す。許可の要る場所を通ることまで含めて確かめるため、ここで通れば実際の会話でも通る。

実際に上限に当たった後は、次で結果を確かめられる。

```shell
tail ~/.claude/resume-logs/detect.log
cat ~/.claude/auto-resume/state.json
```

## 止め方

どちらか一方で仕組み全体が止まる。

- `config.json` の `enabled` を `false` にする。
- 環境変数 `CLAUDE_AUTO_RESUME` に `off`（`0`・`false` も可）を入れる。

すでに待っている処理も止めたい場合は、次で番号を調べて終わらせる。

```shell
cat ~/.claude/auto-resume/state.json
kill <pid>
```

## しきい値

`config.json` にまとめてある。

| 項目 | 既定 | 意味 |
| --- | --- | --- |
| `enabled` | `true` | 仕組み全体の有効・無効 |
| `maxResumesPerSession` | `3` | 同じ会話を再開する上限の回数。再開してすぐまた上限に当たる場合の空回りを防ぐ |
| `resetBufferMinutes` | `3` | 解除時刻に足す余裕 |
| `lateLimitMinutes` | `720` | この分数を超えて遅れたら再開しない。長く触っていない端末が古い作業を突然動かすのを防ぐ |
| `resumePrompt` | — | 再開したときに最初に渡す指示 |

## 記録

すべて git の管理外に残る。

- `~/.claude/resume-logs/detect.log` — 判定と再開の結果が一行ずつ。何もしなかった理由もここに残る。
- `~/.claude/resume-logs/<再開時刻>_<セッションID>.log` — 再開した会話の出力。
- `~/.claude/auto-resume/state.json` — 会話ごとの再開回数、待っている処理の番号、最後の結果。
